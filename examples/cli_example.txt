Available CLI commands:

  gen-key
  encrypt
  decrypt

Usage examples
--------------

Generate an unencrypted keypair:
    qcrypto gen-key --alg kyber768 --public pub.key --private priv.key

Encrypt a file:
    qcrypto encrypt --pub pub.key --in notes.txt --out notes.enc

Decrypt a file:
    qcrypto decrypt --key priv.key --in notes.enc --out notes.dec.txt


Passphrase-protected keys
-------------------------

Generate a keypair encrypted with a passphrase (inline):
    qcrypto gen-key --alg kyber768 --public pub.key --private priv.key --pass "mypassword"

Generate a keypair and prompt securely for the passphrase:
    qcrypto gen-key --alg kyber768 --public pub.key --private priv.key --pass

Decrypt a file using a passphrase-protected private key:
    qcrypto decrypt --key priv.key --pass "mypassword" --in notes.enc --out notes.dec.txt

Decrypt and prompt for passphrase interactively:
    qcrypto decrypt --key priv.key --pass --in notes.enc --out notes.dec.txt
